# E-Commerce Web Application – End-to-End QA Testing

## 1. Project Overview

This project focuses on performing end-to-end Quality Assurance testing of an e-commerce web application. The project covers manual testing, functional testing, UI automation, API testing, and performance testing.

The objective is to identify functional issues, verify expected system behavior, validate critical user journeys, and demonstrate practical QA engineering skills.

## 2. Application Under Test

**Application:** Automation Exercise
**URL:** https://www.automationexercise.com/
**Application Type:** E-Commerce Web Application
**Testing Role:** QA Engineer

## 3. Project Objectives

The main objectives of this project are:

* Understand the application's business flows and functional requirements.
* Identify important application modules and user journeys.
* Design and execute functional test scenarios and test cases.
* Perform exploratory testing to identify unexpected defects.
* Document defects using professional bug reports.
* Automate critical UI test scenarios.
* Perform API testing for available application APIs.
* Conduct basic performance testing using Apache JMeter.
* Generate test reports and document testing results.
* Maintain the project using Git and GitHub.
